# Agar.io Advanced Customization Extension

An advanced extension to customize and enhance your **Agar.io** gameplay experience. It lets you configure UI themes, custom ball colors, smart map bounds, helper lines, and block annoying ads for a smoother, professional experience.

---

## Features
- **UI Themes & Tweaks:** Switch between multiple modern and stylish leaderboard themes.
- **Ball Color Customization:** Set custom fixed ball colors or enable the RGB animation effect.
- **Smart Map Bounds:** Enable map boundary lines for better spatial awareness.
- **Helper Lines (Tracers):** Display helpful tracer lines to guide your movement.
- **Advanced Ad Blocker:** Block full ads to enjoy an uninterrupted gaming experience.
- **Multi-language Support:** Full support for both Arabic and English interfaces.

---

## Installation & Usage
1. Load or install the extension into your userscript manager (e.g., Tampermonkey, Violentmonkey).
2. Open **Agar.io** and press **F1** to toggle the configuration menu.
3. Customize your settings and enjoy the game!
